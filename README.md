# SynthCanvas

SynthCanvas is a node-graph-based mobile synthesizer/DAW. Currently primarily developed for Android tablets, with plans to expand cross-platform in the future.

SynthCanvas is written using the [CLAP](https://github.com/free-audio/clap) API, and [Oboe](https://github.com/google/oboe) is used for high-performance audio experience on Android.
